# WeWeArt Index — 当代艺术话语权平台 · 网站原型

基于你与 DeepSeek 沟通打磨的《当代艺术话语权平台与价值生态建设方案（终极版）》生成的全站可运行 HTML 原型。目标是先让你**完整感受网站全貌**，再逐步优化。

## 如何查看

**方式一（推荐）：单文件版 `single.html`**
双击 `single.html` 即可浏览全站——11 个页面、样式、脚本已全部合并进这一个文件，页面间通过锚点切换，不依赖任何文件间的相对链接解析。板块切换由点击事件显式驱动（不依赖浏览器 hash 事件），兼容 file:// 直接打开与各类浏览器。如果浏览器劫持/拦截导致多页版跳转异常，请优先用这个文件验证（若连它都跳陌生网站，则可确认是浏览器被劫持，与网站无关）。

**方式二：多页版**
直接用浏览器打开 `index.html`（无需安装任何依赖、无需服务器），页面间通过相对链接导航。

```
双击 index.html 或拖入浏览器
```

页面间导航已全部连通（导航栏 / 页脚 / 各类卡片链接），可以像真实网站一样浏览全站。修改多页版后，可用 `powershell -File build-single.ps1` 重新生成单文件版。

## 设计系统（与方案一致）

- **风格**：瑞士国际主义网格 · 极简高级灰 · 数据感（参考 Monocle × Artsy）
- **主色** `#1A1A1A` / 纸色 `#F7F7F7` / 强调薄荷绿 `#00C8A0` / 数据橙 `#FF6B35`
- **字体**：Inter / 系统无衬线（含 PingFang SC、微软雅黑回退）
- **响应式**：桌面 / 平板 / 手机三档断点，移动端汉堡菜单
- 共享样式与脚本：`assets/css/style.css`、`assets/js/main.js`（导航、页脚、订阅弹窗均由此注入，改一处全站生效）

## 已实现的交互（原型演示级）

- 首页 Hero 轮播自动切换（可点击圆点/箭头）
- 数字卡片滚动动画
- 资讯列表地区/时间筛选（真实过滤）
- 评论发布（追加到列表）
- 订阅弹窗（提交后给出成功反馈）
- 今日日期与日报期号动态生成
- 日历导出 .ics、日报「导出 PDF」走浏览器打印

## 数据说明

**文章内容**：全球资讯页共 66 篇**真实新闻**（ARTnews 18 + 雅昌艺术网 22 + Hypebeast 26），标题编译为中文，链接指向原文站，全部经 HTTP 200 逐条验证可访问；首页轮播、阅读榜、资讯详情页、用户中心收藏/推送均引用同一批真实新闻。

**日报（真实新闻版）**：`report.html` 的当日速览、六大赛道复盘、交易数据精选、趋势小结、近期活动预告全部由真实新闻构成，条目链接原文；`reports.html` 归档为按来源分组的真实报道精选。

**全站数据真实化**：首页数据速览、分类报道数、活动预告、资源库统计、艺术家/机构档案（KAWS、贝浩登）均已改为真实公开信息与真实报道链接；影响指数为平台演示指标（页脚已说明）；图片为无版权占位图（正式版替换为真实作品图）。

**站内功能页**（行业日报、艺术家/机构档案、活动日程、用户中心等）为平台功能原型，其中的报告、档案、日程数据为**示例占位**（页面内已标注"原型演示"），正式版接入运营数据与真实 PDF 导出。

**链接完整性**：已修复全部占位链接（`href="#"` 清零）——用户中心侧栏为可交互面板切换、报告检索/隐私政策/版权声明等均指向真实内容区块；板块导航在单文件版由点击事件显式驱动，不依赖浏览器 hash 事件。
